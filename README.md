# rgmantovani.github.io

Personal academic page (PT/EN), plain HTML/CSS/JS — no build step.

- `index.html` — all sections; each text appears twice, as `lang="pt"` and `lang="en"`.
- `assets/publications.js` — publication list (add new entries at the top).
- `assets/main.js` — language switch and publication filters.

Preview locally:

```bash
python3 -m http.server 8000
```
